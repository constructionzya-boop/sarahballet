# Spécification — « Pack Façade Finie » V1 (décision d'orientation)

> Réponse à la question : quel est le meilleur système pour climat africain
> chaud-humide + rendu « maison finie » habitable + usage local commercial ?
> Verdict issu de : analyse Lidget (§1-6), vidéo de montage décodée,
> analyse multi-experts contre-vérifiée, études ETUDE-OPTI / TOITURE /
> MEP, étude Prouvé. ⚠️ Hypothèse V1 — à valider (moule d'essai + test
> marché photo + ingénieur agréé).

## Décision d'architecture

**Structure Noéma inchangée** (poteaux rainurés + P1 horizontaux empilés +
toit parasol) — le pivot vertical type Lidget est REJETÉ pour V1 :
enrobage 27 impossible en peau mince, casse au démoulage à h.2700
(marge <1), engin requis, perte de l'actif récupérable. L'esthétique
recherchée est transférée à la PEAU, pas à la structure.

## Déclinaison Box Commerce

P9 + rideau métallique · auvent 800 = **véranda commerciale** (étal ombré)
· bandeau-enseigne peint au-dessus du linteau · P1G guichet en option ·
version « rangée » mitoyenne pour marchés/mairies (démontabilité
individuelle à étudier [TBV]).
