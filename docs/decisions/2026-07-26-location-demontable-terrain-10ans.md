# DÉCISION — Location démontable RÉTABLIE, sous condition foncière 10 ans

> Décideur : Jeremy (fondateur) · 2026-07-26 · Statut : **ACTÉE**.

> (docs/decisions/2026-07-19-fin-demontage.md) : celle-ci reste valable

> LOCATION démontable. Tous les agents intègrent au prochain `git pull`.

## La décision (deux familles de modules)

1. **VENDU = DÉFINITIF (« en dur »)** — inchangé depuis le 19/07 :
   empilage à sec puis **rainures coulissées au mortier**, scellement 400 +
   dalle. Aucune reprise. C'est l'offre « du dur posé en 1 jour ».
2. **LOCATION = DÉMONTABLE, uniquement sur foncier sécurisé ≥ 10 ans** :
   - le module n'est déployé QUE sur un terrain dont la jouissance est
     garantie **10 ans minimum** : terrain PRIS À BAIL PAR NOÉMA (modèle
     privilégié — nos « parcs ») ou bail/titre du client enregistré ≥ 10
     ans [cadre juridique TBV juriste] ;
   - joints à sec (garnitures, PAS de coulis) ; assise réversible
     SIMPLIFIÉE : plots béton + platines de pied boulonnées 4×M12 —
     le skid complet (rails + traverses + pieds M24) reste supprimé
     [détail assise TBV BET] ;
   - **règle d'exploitation : en cas d'impayé on ne démonte PAS, on
     remplace le locataire** — le module reste sur site. Le démontage est
     un DERNIER RECOURS (perte du foncier, fin de parc), budgété comme
     événement exceptionnel (~1 fois / 10 ans / module [HYP]).

## Le raisonnement économique (à conserver)

Un cycle démontage-remontage ≈ 2 jours d'équipe + transport + remise en
état (joints, épaufrures) + vacance ≈ **3 à 5 mois de loyer** [HYP TBV
chiffrage]. La rentabilité locative exige donc que la rotation se fasse
PAR LE LOCATAIRE, jamais par le module. Le foncier ≥ 10 ans est la
condition qui rend cela possible ; la démontabilité redevient une
ASSURANCE (valeur résiduelle de l'actif), plus un process courant.

## Garde-fous commerciaux

- Impayés : la protection primaire = acompte/caution + scoring +
  remplacement du locataire ; la reprise physique n'est PAS l'argument.
- Le marketing peut de nouveau parler de location, avec le bon angle :
  « votre commerce dans un parc Noéma » / bail sécurisé — PAS « on vient
  reprendre le module » .
- Location-accession : redevient possible sur les mêmes terrains
  sécurisés (coulis posé à la levée d'option) [juridique TBV].
